# Product Overview

React Scheduler is an open-source, TypeScript-oriented, lightweight React component library for creating Gantt charts and timeline schedulers.

## Key Features

- Canvas-based rendering for high performance with large datasets
- Multiple zoom levels (weeks, days, hours)
- Resource scheduling with occupancy tracking
- Internationalization support (en, pl, es, de, lt)
- Theme support (light/dark mode)
- Pagination for handling large datasets
- Tooltip display on hover
- Filter capabilities
- Date range navigation

## Target Use Cases

- Project management timelines
- Resource allocation visualization
- Team scheduling
- Gantt chart displays
- Calendar-based planning tools

## Distribution

Published as `@bitnoi.se/react-scheduler` on npm. The library exports both ESM and UMD formats with TypeScript definitions.
